# Domain Documentation

This repository follows a **single-context** layout.

## Structure

- **`CONTEXT.md`**: Found at the repo root. Contains the project's domain language, core concepts, and high-level architecture.
- **`docs/adr/`**: Directory for Architectural Decision Records.

Skills like `improve-codebase-architecture` and `diagnose` will look for these files at the root to understand the project's context.
