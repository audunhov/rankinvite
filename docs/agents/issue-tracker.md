# Issue Tracker - GitHub

Issues for this repository are tracked using GitHub Issues.

## Workflow

- **Reading:** Use `gh issue list` and `gh issue view <number>`.
- **Creating:** Use `gh issue create --title "<title>" --body "<body>"`.
- **Updating:** Use `gh issue edit` or `gh issue comment`.

Engineering skills like `to-issues` and `triage` will use the `gh` CLI to interact with the tracker. Ensure you are authenticated with `gh auth login`.
